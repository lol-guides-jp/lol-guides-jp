# ガイド記事 共通ライティングルール

対面ガイド生成（gen-matchup / gen-matchup-lite）・ガイド更新（update-guides）・レビュー（review-guide）すべてに適用される。

---

## スキルCDの秒数を書かない

スキルのクールダウン秒数はパッチごとに変わるため、具体的な数値を記載しない。

- **NG**: 「壁キック後は約16秒の間エンゲージ手段がない」
- **OK**: 「壁キック後はしばらくエンゲージ手段がない」
- **OK**: 「W使用後はCCを解除できないウィンドウがある」

サモナースペル（フラッシュ・ゴースト・テレポート）は全チャンプ共通のため write-matchup.md の別ルールに従う。

## "AD carry" は使わない

チャンピオンの役割説明に "AD carry" / "ADC" を使わない。ポジション（ADC）と役割が混同されやすいため。

- **NG**: 「AD carryとしてスケールする」
- **OK**: 「ダメージディーラーとしてスケールする」「クリティカルキャリーとして」「後衛アタッカーとして」

## "処刑" の誤用禁止

「処刑」はゲームメカニクスの固有語（アーゴットR・パイクR等のHP閾値処刑）として使われる。日常語の「素早く倒す」「瞬殺する」の意味で使わない。

- **NG**: 「Q2トゥルーダメージで処刑する」「敵キャリーを処刑できる」
- **OK**: 「Q2トゥルーダメージで瞬殺する」「敵キャリーを落とせる」

## CCの複合仕様は書かない

「内側がスタン・外側がスロー」「段階的にCC種類が変化する」等の複合仕様はハルシネーションリスクが高い。
research JSONに明示されていないCC種類は推測で書かない。

- **NG**: 「W（タクティカルスイープ）の内側半分でスタン」（← research未確認の複合仕様）
- **OK**: 「W（タクティカルスイープ）のCCに注意」「W（タクティカルスイープ）を受けると動きを止められる」
- research JSONにCC種類が明記されている場合のみ「スタン」「スロー」等を具体的に書いてよい

## 馴染みのない横文字（カタカナ語）は日本語にする

意味が日本語で通る横文字は日本語に言い換える。判断基準は「初級〜中級プレイヤーが説明なしで意味を取れるか」。

下表の語は必ず置換する（左NG → 右OK）。

| NG（横文字） | OK（日本語） |
|---|---|
| パックメイト | 猟犬（ナフィーリの使い魔） |
| ギャップクローザー | 接近スキル |
| ギャップクローズ | 接近 / 距離を詰める |
| スカーミッシュ | 小規模戦闘 |
| レーンブリー | レーン制圧役 / 対面を押し込む |
| イモビリティ | 低機動 / 機動力がない |
| モビリティ | 機動力（※アイテム「モビリティブーツ」はそのまま） |
| シージ | 包囲 / タワー攻め |
| アーリーゲーム | 序盤 |
| ミッドゲーム | 中盤 |
| レイトゲーム | 終盤 |
| デュエル | タイマン / 1v1 |

**表に無くても、説明なしで意味が通じにくいマイナーな横文字を見つけたら日本語に言い換える。**

そのまま使ってよい定着語（言い換え不要）: ポーク / エンゲージ / ピール / トレード / オールイン / バースト / ハラス / ゾーニング / ブリンク / スプリットプッシュ / フランク / キャッチ / ダイブ / パワースパイク。

## パワースパイクはコア換算で書く

パワースパイクの強さは「コア数」を主軸に書く。特定アイテム名の羅列はメタ変動で古くなるため避ける。

- 主軸は **何コア完成で強くなるか**（1コア / 2コア / 3コア）
- 現パッチの主力アイテムは **括弧で補足**してよい（日本語正式名のみ。items-ja.json 準拠）
- 英語アイテム名（Essence Reaver / Spear of Shojin 等）・略称（IE / BotRK）は使わない

- **NG**: 「Essence Reaver + Spear of Shojin 完成で一気に強くなる」
- **NG**: 「ナビ・エッジ完成で強い」（アイテム名だけ。コア数が不明）
- **OK**: 「1コア（現パッチ主力: エッセンスリーバー）完成でダメージが一段上がる」
- **OK**: 「2コアそろうと集団戦の継続火力が跳ね上がる」

## レベル表記は「Lv」を付ける

チャンピオンレベルを指すときは裸の数字でなく `Lv` を付けて統一する。

- **NG**: 「6以降の集団戦が強い」「11で2段階目」
- **OK**: 「Lv6以降の集団戦が強い」「Lv11で2段階目」
- **例外**: スキルランク（例「Q ランク3以降」）はチャンピオンレベルではないので `Lv` を付けない。両者を混同しない
