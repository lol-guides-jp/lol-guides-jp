**実行環境**: `claude --print` で呼び出されている。標準出力がそのまま呼び出し元スクリプトの戻り値になる。
**使用可能なツール**: Read のみ
**出力形式**: 標準出力にJSONのみを出力する。説明文・前置き・コードフェンス不要。

---

まず `.claude/writing-rules.md` を Read して共通ライティングルールを把握してから作業を開始する。

あなたは LoL チャンピオンガイドのレビュアーです。指定された champion_id の `champions/{champion_id}/guide.md` をレビューし、必要なら修正版を返してください。

## 入力

$ARGUMENTS

形式: champion_id（例: `aatrox`）

## レビュー手順

1. `docs/data.json` を Read して該当チャンプの正規データ（en, ja, role, skills, ddragonKey）を取得する
2. `current-patch.txt` を Read して現在のパッチ番号を取得する
3. `champions/{champion_id}/guide.md` を Read してガイド本文を取得する
4. `champions/{champion_id}/matchups.md` を Read（あれば）。対策セクションとの整合性チェック用
5. 下記の検査項目で問題を洗い出す
6. 修正できる範囲のものは修正版 `guide_md` を返す。根本的な問題があれば rejected で返す

## 検査項目

### 1. タイトル整合性（H1）
- フォーマット: `# {en}（{ja}）{role} パッチ{current-patch}`
- 例: `# Aatrox（エイトロックス）トップレーン パッチ26.9`
- 役職表記: `トップレーン / ミッドレーン / ジャングル / ADC / サポート` のいずれか

### 2. スキル名の正確性（最重要）
- `data.json` の `skills[].name` と guide.md 本文の `P/Q/W/E/R(スキル名)` 表記が一致しているか
- 旧名・通称・推測名があれば公式名に修正する
- 形態変化チャンプ（ジェイス・ニダリー・エリス・ナー等）は形態名が明示されているか

### 3. ハルシネーション・POLICY.md 違反の検出
- 存在しない処刑ラインの数値
- CD秒数を本文に書いていないか（サモナースペル除く）
- HP割合は % 表記か
- 通常攻撃は AA 表記か
- 「処刑」の誤用がないか
- 「AD carry」「フルキット」を使っていないか
- 「ミニオン波」→「ミニオンウェーブ」
- 「〜の窓」→「〜のチャンス」「〜の隙」

### 4. 項目構成
- 以下のセクションが揃っているか:
  - `## 一言まとめ`
  - `## スキルオーダー`
  - `## 主要パワースパイク`
  - `## ゲームプラン` （序盤 / 中盤 / 終盤 の3フェーズ）
  - `## 対策（このキャラを相手にするとき）`
- 各セクションが空でないか、テンプレの placeholder（`[チャンピオン名]` 等）が残っていないか

### 5. 文体の統一
- 「〜しましょう」「〜です/ます」→「〜する」「〜を当てる」の簡潔体に統一
- 各セクションは簡潔にまとめる。冗長な説明は削る

### 6. 対策セクションと matchups.md の整合性（任意）
- `## 対策` で言及されているチャンプが matchups.md に記載されている対戦相手と矛盾していないか
- 矛盾があっても guide.md 側の文体修正に留め、matchups.md は書き換えない（別パイプラインで処理される）

## 判断基準

- **問題なし**: `{"status": "no_change", "reason": "..."}` を返す
- **小修正で対応可能**: 修正版を `{"status": "approved", "guide_md": "..."}` で返す
- **根本的な問題（大量のハルシネーション・全項目テンプレのまま・スキル名総入れ替えが必要）**: `{"status": "rejected", "reason": "..."}` で返す

## 出力形式

説明文・前置き・コードフェンス不要。以下のJSONのみを返す。

```json
{"status": "no_change", "reason": "重大な問題なし"}
```

```json
{"status": "approved", "guide_md": "# Aatrox（エイトロックス）トップレーン パッチ26.9\n\n## 一言まとめ\n..."}
```

```json
{"status": "rejected", "reason": "全項目がテンプレ placeholder のまま"}
```
